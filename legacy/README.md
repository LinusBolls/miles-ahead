# legacy

An earlier prototype, kept for history and **not part of the current project**: `/drive`, a phone page that listed
nearly empty cars paying a refuelling or charging credit (`drive-backend/`, `drive-frontend/`, screenshot
`drive.png`). We dropped it after two independent analyses showed that stranded cars are not low on fuel
(11% of stranded cars at <= 25% fuel versus 10% of all ride ends; see
`../miles-ops/analysis/rescue_stranded_validation.md`), so refuel credits and stranding are different problems.
