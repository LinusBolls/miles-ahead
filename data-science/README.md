# data-science

Reserved for **Carolina's TabPFN work** (Prior Labs). Her evaluation and modelling scripts — the clean June 3–16 /
June 17–23 train/test split, the Berlin 10k-context vs. 210k-row GBM comparison, cold-start curves across cities, and
the calibration analysis — live here.

The headline numbers these scripts produce are summarised in the root `README.md` and stored in
`../ops-backend/model/tabpfn_meta.json` (`metrics_carolina`).

Please keep raw data (parquet dumps, car positions) out of this directory — see the repo `.gitignore`.
